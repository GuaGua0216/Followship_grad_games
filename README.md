# 團契送舊大挑戰：大學生生存遊戲 (College Survival Game)

這是一款專為大專團契「送舊活動」設計的多人互動網頁遊戲。遊戲模擬了大學生從大一到大四的旅程，玩家必須在物價不斷波動的市場中做出購買決策。這不僅是運氣的考驗，更是一場充滿「投資感」的生存挑戰，快來體驗充滿驚喜的大學生活吧！

## 遊戲背景與特色
* **送舊專屬**：為大一到大四的團契契友量身打造，在遊戲中回顧大學四年的階段變化。
* **市場投資機制**：商品的價格會隨著「年級（大一至大四）」產生波動。玩家在購買當下可以看見當前物價，但無法預測未來的漲跌。你該趁低價囤貨，還是保留現金？考驗你的投資眼光！
* **匿名排行榜**：遊戲支援匿名參與，玩家可以在開局時輸入專屬暱稱。當大學四年順利「畢業」後，系統將結算最終資產並顯示全局排行榜，看看誰才是團契中的「生存理財大師」！

## 遊戲規則與流程
每位玩家開局皆有 **30 元** 的起始資金，遊戲一共分為四個回合（大一至大四），主要包含以下核心畫面：

1. **畫面一：登入與開始 (Login & Start)**
   - 玩家輸入自訂的「匿名暱稱」。
   - 點擊「開始遊戲」按鈕，正式踏上大學旅程。
   - 系統發放起始資金 30 元。

2. **畫面二：選擇年級 (Select Grade)**
   - 玩家依序進行當前階段（大一、大二、大三、大四）。
   - 遊戲將強制或引導玩家從「大一」開始，逐年升級。

3. **畫面三：購買商品 (Buy Items)**
   - 畫面上提供 3 種商品，並**公開標示它們在「當前年級」的價格**。
   - **挑戰點**：雖然知道現在的價格，但未來的物價是未知數（價格陣列如 `ItemA: [3, 5, 1, 2]` 已在系統背景設定好）。玩家必須評估手邊餘額與未來風險，輸入「購買數量」。
   - 確認數量後點擊「確定」，系統將進行扣款運算。

4. **畫面四：階段結算 (Stage Results)**
   - 畫面顯示：`「恭喜從 {大X} 畢業了！」`
   - 系統結算並顯示玩家剛剛的總花費，以及最新的「剩餘餘額」。
   - 提供「進入下一年級」按鈕，直到大四結束。

5. **畫面五：最終排行榜 (Leaderboard)**
   - 大四畢業後，進入遊戲最終環節。
   - 系統統整所有參與者的最終剩餘餘額（或總資產價值），列出排名。
   - 大家可以一起在送舊現場看著排行榜歡呼或吐槽！
